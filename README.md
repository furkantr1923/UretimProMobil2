İki tam ürün geliştirdim. ÜretimPro, metal parça üreten fabrikalar için bir üretim izlenebilirlik ve kalite sistemi. Backend’de C# ve ASP.NET Core MVC (.NET 10), veri katmanında Entity Framework Core ile SQLite kullandım. Böylece kurulum gerektirmeden USB’den exe olarak, internetsiz çalışıyor. İş kurallarını servis katmanında yazdım ve xUnit ile test ettim: SPC’nin Western Electric kuralları, OEE hesabı, Pareto analizi, FIFO ve bakım planı. Canlı bildirimler için Server-Sent Events kullandım. PDF raporları QuestPDF, Excel çıktıları ClosedXML ile üretiliyor. Dışarıya REST API açtım ve Swagger ile dokümante ettim. Projeyi Docker ile paketledim, GitHub Actions ile her push’ta otomatik derleniyor ve test ediliyor. Güvenlik tarafında şifreler hash’leniyor, hatalı girişte hesap kilitleniyor, CSRF koruması ve rol bazlı yetki var. Silinemez bir audit log tutuluyor. Uygunsuzluk raporları SHA-256 ile mühürlenen elektronik imzayla onaylanıyor. Mobil tarafta .NET MAUI Blazor Hybrid ile aynı kuralları kullanan bir Android uygulaması yazdım: ZXing ile kamerayla QR okuyor, cihazdaki SQLite’a kaydediyor ve internet yokken bir kuyrukta biriktiriyor. Daha önce de aynı teknolojilerle bir doğal gaz arıza takip sisteminin web ve Android sürümünü geliştirdim.
